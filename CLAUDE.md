# CLAUDE.md

Guidance for Claude when working in this repository.

## Rules

- **Build name in every summary.** Whenever you finish a task and write a summary of the implemented changes,
  include the name of the build that contains them, for example `build-30-1bca82e` (branch builds are
  `build-<run_number>-<sha7>`; builds of `main` are `0.x.0`). Get it from the GitHub Actions run of your last
  push (the job summary, the release or the GitHub Pages folder).
- **English everywhere in the code base:** code comments, Markdown files, and names of types, functions,
  variables, methods, files, etc. Only user-facing strings are translated (see Localization).

## Project

- iOS app written in SwiftUI (iOS 17+). No third-party dependencies; keep it that way unless there is no
  reasonable alternative.
- The Xcode project is generated by XcodeGen from `project.yml`; never commit `*.xcodeproj`.
- Bundle ID comes from the `APP_BUNDLE_ID` build setting (`com.leonardoramirezr.itinerarybyleoneralabs`).
  Extensions, if any, must use `$(APP_BUNDLE_ID).<suffix>`.
- Do not add App Groups or other capabilities that Xcode cannot register with the App Store Connect API key
  alone (CI uses automatic signing).
- Swift 5 language mode with minimal concurrency checking. UI-facing state lives in `@MainActor @Observable`
  classes (`SettingsStore`, `ItineraryStore`, `GoogleAuthService`, `CaptureModel`, `AudioRecorder`).

## Architecture

- `Models/` — `AppSettings` (persisted as JSON in UserDefaults, every field decoded independently),
  `LLMProvider`/`ProviderConfig`, `PromptKind` + `DefaultPrompts`, `Itinerary`, routines, places.
- `Services/` — `OpenAICompatibleClient` (`/chat/completions`), `TranscriptionService` (Groq
  `/audio/transcriptions`), `ItineraryPlanner` + tolerant `ItineraryParser`, `GoogleAuthService` (OAuth PKCE via
  `ASWebAuthenticationSession`), `GoogleCalendarAPI`, `SystemCalendarService` (EventKit), `FixedEventsLoader`,
  location search and commute estimation (MapKit), `AudioRecorder`.
- `Views/` — onboarding, home with the two timeline modes (`UniformTimelineView`, `ProportionalTimelineView`),
  dictation (`CaptureView`), settings.
- API keys and Google tokens are stored in the Keychain (`KeychainStore`). The Groq key is shared by speech to
  text and the Groq LLM provider.
- Every prompt is editable in Settings; when you add a prompt, add a `PromptKind` case with its default text.

## Localization

- English and Spanish `.strings` files in `Itinerary/Resources/{en,es}.lproj/`. Keys are the English text.
- Use `String(localized:)` for strings built in code and `LocalizedStringKey` literals in SwiftUI views.
  Use `Text(verbatim:)` for user or model content.
- Add every new string to both files and run `python3 scripts/check-localizations.py` (CI runs it too).
- Interpolations become format specifiers: `String` → `%@`, `Int` → `%lld`.

## CI/CD

- `.github/workflows/build.yml` builds every push on `macos-15`, signs Ad Hoc, publishes to GitHub Pages
  (`gh-pages`) and creates a release. See the README for secrets and behavior.
- Helpers: `scripts/asc.py` (App Store Connect API, stdlib + `openssl`), `scripts/pages.py` and
  `scripts/publish-pages.sh` (GitHub Pages), `scripts/check-localizations.py`.
- There is no Xcode in the Linux development container; the CI build is the compile check. After pushing,
  check the workflow run and fix any failure before reporting the task as done.
